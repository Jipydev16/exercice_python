# Votre zone d’essai

Ces 15 fichiers contiennent les signatures à compléter. Remplacez `raise NotImplementedError` par **votre** algorithme. Les corrigés complets sont conservés séparément dans `exercices/` pour que vous puissiez chercher sans voir la réponse.

Exemple : `python mes_essais/exercice_01.py` (ajoutez un bloc `if __name__ == "__main__":` pour afficher un résultat).
